# Every Python package Databricks Runtime 17.3 LTS ML installs, at the version
# it installs, one name==version per line. Captured from a clean cluster with no
# libraries, through the notebook's own interpreter:
#     %sh $(python -c 'import sys; print(sys.executable)') -m pip list --format=freeze
# Not /databricks/python3/bin/pip. On a cluster with libraries that one does not
# see them, because cluster libraries install into a different environment.
#
# regenerate.py resolves the lock against all of these, so every runtime
# package's own dependency bounds hold, which is what pip check tests. A pin
# left as it is keeps the runtime's copy in place. Two markers take a line out,
# and each one needs a reason:
#     # freed: name==version  reason
#         The labs need a different version. The package stays in the resolve
#         by name, so its dependents' bounds still apply to whatever moves it.
#     # not-required: name==version  reason
#         Left out of the resolve altogether: not on PyPI, or already broken on
#         a clean cluster. Nothing is checked against it.
# Any other commented-out pin fails the check.
#
# Moving the course to another runtime means capturing that runtime's list the
# same way, re-marking these lines, then regenerating the lock.
